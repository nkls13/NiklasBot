No new npm dependency, so nothing to flag as paid/added per that same rule — but swapping the planned package is itself a deviation from the docs worth recording. Added `"engines": {"node": ">=22.5.0"}` to `package.json` to document the new floor. If `better-sqlite3` is ever specifically wanted (e.g. to drop the experimental warning, or for features `node:sqlite` lacks), swapping the storage backend inside `lib/textMemoryStore.js` is a self-contained change — nothing in `index.js` talks to SQLite directly.
